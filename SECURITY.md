# Security policy

## Supported version

Security and crash-safety fixes target the latest published UHM release.

## Reporting a vulnerability

Please report a reproducible security, arbitrary-file-write, or crash-safety issue privately to the repository owner before opening a public issue. Include the UHM version, Skyrim runtime, SKSE version, relevant log excerpt, and minimal reproduction steps. Do not include save files or logs containing private paths unless they are necessary and redacted.

Ordinary scanner misses, unsupported hotkey formats, and UI defects may be reported through the public issue tracker.
